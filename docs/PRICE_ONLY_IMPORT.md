# นำเข้าเฉพาะราคาขาย

หลังอัปเดตแอป ใช้ **สต็อกสินค้า → ปรับราคาหลายรายการ → อัปโหลดไฟล์ราคาขาย**

ไฟล์ Excel (1 ชีต) หรือ CSV ขนาดไม่เกิน 5 MB ต้องมี 2 คอลัมน์ตามลำดับ:

```csv
บาร์โค้ด,ราคาขาย
01,2.00
8850580200039,5.00
```

- จับคู่บาร์โค้ดตรงตัว รวมศูนย์หน้า ไม่จับคู่ชื่อและไม่สร้างสินค้าใหม่
- หากมีรหัสไม่พบ รหัสกำกวม รหัสซ้ำ หรือราคาผิด จะยังไม่ใส่ค่าจากทั้งไฟล์ลงตาราง ต้องแก้ไขไฟล์ก่อน
- ล้างค่าที่กรอกค้างไว้ก่อนอัปโหลด เพื่อไม่ให้ไฟล์ทับการแก้ไขที่ยังไม่บันทึก
- การอัปโหลดใส่เฉพาะราคาขายใหม่ในตาราง ไม่บันทึกทันที ตรวจตารางแล้วกดบันทึกและยืนยัน
- ช่องต้นทุนใหม่ยังว่าง สต็อก ต้นทุน และราคาของบิลเดิมไม่เปลี่ยน
- ราคาที่ตรงกับข้อมูลเดิมจะไม่ถูกส่งไปแก้ซ้ำ การบันทึกใช้ธุรกรรมเดียวและลงประวัติการปรับราคา
- ไม่ใช้หน้าตั้งค่า → นำเข้าสินค้าทั่วไป สำหรับไฟล์ราคาขายสองคอลัมน์นี้

Validation: TypeScript and production builds passed. Full regression: 348 tests / 47 files passed. An isolated browser run uploaded 221 Excel price rows, rejected an invalid file, cancelled review without writes, then applied all prices and verified unchanged stock, catalog costs, lots, bills, wallets and stock movements. The shop's business database was not accessed.
