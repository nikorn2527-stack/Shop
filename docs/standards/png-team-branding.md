# มาตรฐานเครดิตทีม

มาตรฐานเดียวกันสำหรับทุกแอปของทีม ตามคำขอวันที่ 13 พฤศจิกายน 2569

| บริบท | ข้อความที่ใช้ |
|---|---|
| UI, Footer, หน้าล็อกอิน, หน้าตั้งค่า, ใบพิมพ์ที่มีเครดิต | `POWERED BY PNG TEAM` |
| ข้อความบรรยาย เอกสาร คำอธิบายโครงการ | `Powered by PNG Team` |

ข้อความเครดิตต้องตรงตามรูปแบบตัวพิมพ์นี้ ไม่ใช้รูปแบบผสม เช่น `Powered by PNG TEAM` การอ้างข้อความ UI แบบคำต่อคำในเอกสารให้คงสตริงของ UI เพื่อให้ตรงกับหน้าจอจริง

ปรับเฉพาะข้อความเครดิตในตำแหน่งที่มีอยู่ คงรูปแบบและพื้นที่เอกสารเดิม หากจะเพิ่มเครดิตใหม่ลงใบเสร็จหรือแบบพิมพ์ ต้องอยู่ในขอบเขตที่ผู้ใช้ขอ ไม่ใช้มาตรฐานนี้เป็นเหตุเพิ่มข้อความท้ายเอกสารเอง

ชื่อทีมเดี่ยว ๆ ในช่องข้อมูลผู้พัฒนายังเป็น `PNG TEAM` ได้ กฎนี้กำหนดรูปแบบของข้อความเครดิตทั้งวลี
