# มาตรฐานลำดับข้อมูลสมาชิก

บันทึกจากความต้องการของผู้ใช้วันที่ 13 พฤศจิกายน 2569 เพื่อใช้กับงานต่อไปและนำไปพัฒนาเป็นสกิลได้

## กฎหลัก

กลุ่มข้อมูลสมาชิกเรียง **เลขบัตร → เลขสมาชิก → ชื่อสมาชิก** ทุกจุดที่มีข้อมูลเหล่านี้อยู่แล้ว ไม่ว่าจะเป็นคอลัมน์ แถวข้อมูล คำยืนยัน ตัวเลือกค้นหา หรือข้อมูลหัวเอกสาร

- มีครบสามช่อง: `เลขบัตร | เลขสมาชิก | ชื่อสมาชิก`
- ไม่มีเลขบัตร: `เลขสมาชิก | ชื่อสมาชิก` ไม่เพิ่มเลขบัตรขึ้นมาเอง
- มีเลขบัตรกับชื่อเท่านั้น: `เลขบัตร | ชื่อสมาชิก`
- ลำดับรายการ วัน–เวลา เลขที่บิล และเลขอ้างอิงของเอกสารอยู่หน้ากลุ่มสมาชิกได้
- ในตารางที่แสดงกลุ่มสมาชิกกับจำนวนเงิน วางจำนวนเงินหลังชื่อสมาชิกตามแบบที่ตกลงกัน ไม่จัดลำดับส่วนสรุปยอดของฟอร์มอื่นใหม่โดยอัตโนมัติ

## ขอบเขต

ใช้ลำดับเดียวกันในหน้าจอ พรีวิว PDF การพิมพ์ CSV และ Excel ทั้งแถวหัวและข้อมูลจริง หากจำเป็นต้องซ้อนข้อมูลในช่องเดียว ให้อ่านตามลำดับเดียวกันจากบนลงล่าง

หัวเรื่องของหน้า ข้อความแจ้งผล และประโยคคำอธิบายไม่ใช่แถวข้อมูล ไม่ต้องย้ายคำในประโยคให้ผิดธรรมชาติ งานออกแบบบัตรสมาชิกที่มีขนาดพิมพ์ตายตัวไม่ถูกจัดใหม่ด้วยกฎคอลัมน์นี้โดยอัตโนมัติ

## สิ่งที่ต้องรักษา

- ไม่เพิ่มช่องที่ผู้ใช้ไม่ได้ขอ โดยเฉพาะเลขบัตรบนสลิปเงินหรือใบเสร็จที่ตกลงให้ไม่แสดง
- คงขนาดชื่อสมาชิกบนใบเสร็จที่ผู้ใช้อนุมัติไว้
- เลขบัตรและเลขสมาชิกเป็นข้อความ รักษาศูนย์นำหน้า ไม่จัดเป็นคอลัมน์จำนวนเงิน
- ชื่อแสดงคำนำหน้าและนามสกุลครบ ไม่ตัดข้อมูลเพื่อให้พอดีช่อง
- รายงานยอดเงินใช้บัตรที่ผูกอยู่ปัจจุบัน ประวัติธุรกรรมใช้เลขบัตรตามประวัติเดิม การย้ายตำแหน่งไม่เปลี่ยนความหมายของข้อมูล
- การเรียงช่องไม่เปลี่ยนลำดับรายชื่อ ยอดเงิน ธุรกรรม หรือการคำนวณ
- ย้ายความกว้างช่อง แถวรวม และดัชนีคอลัมน์ตัวเลขให้ตรงกับหัวใหม่เสมอ

## การตรวจรับ

ตรวจทั้งหัวและค่าข้อมูลจริง รวมกรณีไม่มีบัตร เลขมีศูนย์นำหน้า ชื่อมีคำนำหน้า ชื่อยาว และยอดศูนย์ เปรียบเทียบ PDF/CSV/Excel ว่าค่าและตำแหน่งสอดคล้องกัน แล้วส่งภาพให้ผู้ใช้ตรวจรูปแบบก่อนนำขึ้นระบบจริง
