# ทางเลือกชื่อ “ปิดบัญชีสมาชิก”

สถานะ: ข้อเสนอ ยังไม่เปิดใช้ในหน้าจอ

ปัจจุบันใช้ “ขอลดวงเงิน” สำหรับคืนเงินทั้งหมดและปิดการใช้งานรอบนี้
โดยยังไม่รับคืนบัตร และ “คืนบัตร” สำหรับรับคืนบัตรจริง
ทั้งสองรายการเก็บเลขสมาชิกและประวัติเดิม ไม่ลบสมาชิก

หากอนุมัติแนวทางใหม่ ให้เปลี่ยนชื่อขอลดวงเงินเป็น “ปิดบัญชีสมาชิก”
พร้อมกันใน POS รายละเอียดสมาชิก ทางลัด ตั้งค่าสิทธิ์ และรายงาน
ใช้ API และกติกาธุรกรรมเดิม ไม่เพิ่มเมนูหรือ API ซ้ำ

รายงานรวมจ่ายนับเฉพาะเงินที่จ่ายจริง การรับคืนบัตรหลังคืนเงินแล้ว
เป็นเหตุการณ์บัตร ไม่สร้างรายการเงินซ้ำ
ห้ามแยกรายงานย้อนหลังจากชื่อเมนูหรือเดาสาเหตุของธุรกรรมเดิม
หากต้องแยกขอลดวงเงินกับคืนเงินพร้อมคืนบัตร ต้องใช้หลักฐานชนิดรายการที่บันทึกไว้

เกณฑ์ตรวจ: คืนเงินโดยไม่คืนบัตร → คืนบัตรภายหลัง → จ่ายบัตรใหม่
ต้องคืนเงินครั้งเดียว บัตรไม่ว่างก่อนรับคืน และเลขสมาชิกไม่เปลี่ยน
