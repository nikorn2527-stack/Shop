# บัตรเปล่าและเมนูการบริหารจัดการ

## การเปลี่ยนแปลง
- หน้าสมาชิกแยกแท็บรายการสมาชิก / จัดการบัตรเปล่า ไม่แสดงทะเบียนบัตรเหนือการ์ดสมาชิก
- ปุ่มเตรียมรหัสจำลอง 20 ใบใช้ DEMO-CARD-00001 เป็นต้นไป ข้ามรหัสที่มีแล้ว ต้องกดเพิ่มบัตรเปล่าจึงบันทึก ไม่ seed ลงฐานจริงอัตโนมัติ
- เลขสมาชิกยังสร้างจากค่าการออกเลขสมาชิกเดิม ไม่ใช้รหัสบัตรเป็นเลขสมาชิก
- เพิ่มเมนูต้นทุนและกำไร ใช้รายงานยอดขาย/ต้นทุน/กำไรขั้นต้นเดิม ไม่ใช่กำไรสุทธิและไม่เพิ่มสูตรบัญชีใหม่
- เปลี่ยนชื่อกลุ่มเมนูเป็น การบริหารจัดการ

## ผลตรวจ
- TypeScript ผ่าน
- Regression 194/194 ผ่าน (19 ไฟล์)
- เพิ่มเทสต์เลขสมาชิก TEST-00001 แล้วคืนบัตรและใช้ซ้ำได้ TEST-00002
- Production build ผ่าน มีคำเตือนขนาด bundle
- Diff check และ syntax สคริปต์ผ่าน
- Browser acceptance ยังไม่ผ่าน: Chrome ปิดก่อนเริ่มหน้า (Target.setDiscoverTargets: Target closed) ไม่ได้ทดสอบคลิกหรือบันทึกรหัสจำลองสำเร็จ
