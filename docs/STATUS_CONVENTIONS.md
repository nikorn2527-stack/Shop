# มาตรฐานสถานะบนหน้าจอ

ป้ายสถานะใช้จุดสีและข้อความตัวหนา ไม่ใช้พื้นสีเต็มป้าย และต้องมีข้อความอธิบายเสมอ ไม่สื่อด้วยสีอย่างเดียว

| สี | ความหมาย | ตัวอย่าง |
|---|---|---|
| เขียว | สำเร็จ หรือพร้อมใช้งาน | บัตรว่าง พร้อมจ่าย |
| น้ำเงิน | อยู่ระหว่างใช้งาน | บัตรใช้งานอยู่ |
| เหลือง | รอดำเนินการ หรือต้องตรวจแก้ | รออนุมัติ สต็อกต่ำ |
| แดง | ใช้ไม่ได้ ถูกระงับ หรือผิดพลาด | บัตรหาย บัตรชำรุด |
| เทา | ข้อมูลทั่วไป หรือสถานะที่ไม่ระบุความสำคัญ | ไม่ระบุ |

ใช้คลาสร่วม `status-pill`, `status-badge` และ `card-inventory-status` ตาม mapping ใน workspace.css ไม่กำหนดสีใหม่เฉพาะเมนู

กล่องแจ้งเตือนและ Dialog ไม่ใช่ป้ายสถานะ: ยังคงใช้พื้นเขียว/เหลือง/แดงตามความสำคัญ เอกสารพิมพ์คงรูปแบบเดิม
