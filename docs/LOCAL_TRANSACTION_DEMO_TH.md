# ชุดธุรกรรมจำลองบน Local

ใช้สำหรับตรวจหน้าจอและรายงานก่อนส่งขึ้นระบบจริง โดยคัดลอกฐานข้อมูล Local ไป `.transaction-demo/store.sqlite` แล้วทำธุรกรรมตัวอย่างผ่านฟังก์ชันธุรกิจเดียวกับแอป ไม่เพิ่มข้อมูลจำลองลงฐานข้อมูลต้นฉบับหรือ Railway และไม่สร้างบัญชี/เปลี่ยนรหัสผ่านผู้ใช้

## เริ่มใช้งานบน Windows

ในโฟลเดอร์ Shop บนสาขาทดสอบ หยุด `pnpm dev` เดิมด้วย Ctrl+C ก่อน:

```powershell
git pull --ff-only
pnpm.cmd demo:transactions
```

เปิด `http://127.0.0.1:3000/` แล้วใช้บัญชีและรหัสผ่าน Local เดิม ชื่อร้านในสำเนาจะแสดงคำว่า **ข้อมูลจำลอง** ชัดเจน ค้นหาคำว่า **ตัวอย่าง** ในหน้าสมาชิกเพื่อดูเฉพาะสมาชิกที่สร้างสำหรับทดสอบ

ฐานข้อมูลต้นฉบับต้องมีสินค้าและบัญชีผู้ดูแลอยู่แล้ว คำสั่งอ่านตำแหน่งต้นฉบับจาก `SQLITE_DB_PATH` ในการตั้งค่า Local หากไม่ได้กำหนดจะใช้ `data/welfare-store.sqlite` ตำแหน่งต้นฉบับต้องอยู่ภายในโฟลเดอร์โครงการและอยู่นอกโฟลเดอร์ชุดจำลอง คำสั่งปฏิเสธการรันในโหมด Cloud/Railway

รันซ้ำจะเปิดชุดเดิมโดยไม่เพิ่มธุรกรรมซ้ำ หากต้องการเริ่มสำเนาจำลองใหม่จากข้อมูล Local ปัจจุบัน ให้หยุดแอปแล้วใช้:

```powershell
pnpm.cmd demo:transactions --rebuild
```

ชุดจำลองเดิมจะถูกสำรองใน `.transaction-demo/backups` ก่อนสร้างใหม่ ดูจำนวนรายการและเลขสมาชิกตัวอย่างได้ที่ `.transaction-demo/SCENARIOS.md` และ `summary.json`

## กรณีที่มีให้ตรวจ

- ขายสินค้าเดิมทุกชนิดที่เปิดขายและตั้งราคามากกว่า 0: เงินสดพร้อมเงินทอน, QR, หักบัญชีสมาชิก, ส่วนลด, สินค้าหลายรายการต่อบิล และจุดขายสองจุด
- เปิดยอดสมาชิก, เติมหลายรอบ, ถอน, ซื้อสินค้า, คืนเงินและคืนบัตร, ยกเลิกบิลคืนเงินและสต๊อก
- สมาชิกยังอยู่ยอด 0 หลังซื้อครบยอดหรือถอนครบยอด — ต้องแสดงในรายงาน
- สมาชิกออกและคืนบัตรทั้งกรณียอด 0 และคืนเงินครบ — ต้องไม่แสดงในรายงานยอดเงิน แต่ข้อมูลสมาชิกและประวัติยังอยู่
- เปลี่ยนบัตร, บัตรเวียนคนใหม่, ยังไม่ได้รับบัตร, ปิดรอบแต่ยังไม่คืนบัตร และปิดรอบพร้อมคืนบัตร
- รับเข้าสินค้าเดิมพร้อมของแถม, เพิ่มสินค้าใหม่พร้อม Item ถัดไป, ต้นทุนต่างรอบ, ปรับราคาขาย, นับสต๊อกแยกล็อต, ล็อตใกล้หมดอายุ, สินค้าคงเหลือ 0 และรายการเตรียมสั่งซื้อ
- ตัวอย่างตัดยอดหนึ่งรอบและเปิด/ปิดกะ โดยยังทดลองขายต่อได้ในรอบปัจจุบัน

รายการเกิดในวันสร้างชุดจำลองและกำกับชื่อสมาชิก/เจ้าหน้าที่ว่าเป็นตัวอย่าง ใช้เฉพาะสำเนาที่เตรียมไว้

## กลับไปข้อมูล Local เดิม

กด Ctrl+C หยุดชุดจำลอง แล้วรัน:

```powershell
pnpm.cmd dev
```

เปิด `http://localhost:3000/` ตามเดิม ไม่มีการกู้ฐานข้อมูลทับต้นฉบับ และไม่ต้องนำไฟล์จำลองไปใส่ Railway
