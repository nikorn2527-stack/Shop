# มาตรฐานสีปุ่มตามหน้าที่

สีหลักเป็นส้ม สีสำเร็จเป็นเขียว LINE ปุ่มที่มีผลกระทบต้องเลือกสีจากหน้าที่ ไม่ใช้สีหลักทับทุกกรณี

| หน้าที่ | ตัวอย่าง | สีพื้น | สีข้อความ |
| --- | --- | --- | --- |
| ทำรายการทั่วไป | เพิ่ม แก้ไข บันทึก ถัดไป ยืนยันบันทึก ยืนยันชำระเงิน | #FFEDD5 | #9A3412 |
| สำเร็จแล้ว | ตกลงหลังสำเร็จ เสร็จสิ้น เริ่มรายการใหม่ | #06C755 | #052E16 |
| ต้องระวัง | ถอนเงิน คืนเงิน คืนบัตร ระงับผู้ใช้ ปิดการขาย ยกเลิกเซสชัน | #FFFBEB | #92400E |
| เริ่มลบ | ลบสินค้า ลบสมาชิก | #FFFFFF ขอบแดง | #B91C1C |
| ยืนยันทำลายข้อมูล | ยืนยันลบ ทิ้งร่าง ล้างรายการ กู้คืนทับฐานข้อมูล | #DC2626 | #FFFFFF |
| ปุ่มรอง | ยกเลิก ย้อนกลับ ปิดหน้าต่าง ล้างตัวกรอง | #FFFFFF ขอบ #CBD5E1 | #334155 |
| ใช้งานไม่ได้หรือกำลังบันทึก | ข้อมูลไม่ครบ รอผล server | #E8ECF1 | #596575 |

คำว่า “ยืนยัน” ไม่ได้กำหนดสีเอง ต้องพิจารณาผลของการยืนยันนั้น สีเขียวใช้หลัง server ยืนยันสำเร็จแล้วเท่านั้น การเปิดใช้งาน/คืนสถานะที่ยังไม่ได้บันทึกใช้สีปุ่มทำรายการทั่วไป

## วิธีใช้ในโค้ด

- ปุ่มทั่วไปใช้ `primary-button` หรือ `data-action-tone="primary"`
- ปุ่มจบงานใช้ `data-action-tone="success"`
- ปุ่มระวังใช้ `data-action-tone="warning"`
- ปุ่มเริ่มลบใช้ `danger-outline-button` ยืนยันลบใช้ `ConfirmDialog tone="danger"`
- ปุ่มรองใช้ `outline-button` และสถานะรอผลใช้ `disabled`/`busy`
- ทุก `ConfirmDialog` ต้องระบุ `tone` โดยตรง TypeScript จะตรวจหากไม่ได้ระบุ
- ผลสำเร็จใช้ `WorkflowResult` หรือ `notify.completed` ซึ่งใช้ `FeedbackDialog` ส่วนกลาง

## สิ่งที่คงเดิม

สวิตช์เปิด #9ED9B7 / ปิด #DCE2EA และสีไอคอนไฟล์ CSV ฟ้า, Excel เขียว, PDF แดง, พิมพ์ม่วง แยกตามหน้าที่เช่นเดิม

## หน้าเข้าสู่ระบบ

- ช่องกรอกและปุ่มใช้กรอบโฟกัสเทาบาง ไม่ใช้ขอบเขียว/แดงเพื่อบอกตำแหน่งเคอร์เซอร์
- การย้ายเครื่องออกจากระบบที่เครื่องเดิม จึงใช้ `FeedbackDialog tone="warning"` และปุ่มเหลืองอ่อน ขณะรอคำตอบป้องกันการกดย้ำและปิด Dialog
- ตั้งค่า → ร้านค้าและหน้าจอ → แบรนด์และธีม → รูปแบบหน้าเข้าสู่ระบบ เลือกภาพโรงพยาบาลหรือภาพอื่นเป็นพื้นหลังได้ (PNG/JPG/WEBP ไม่เกิน 2MB)
- ภาพหน้า login แยกจากภาพพื้นที่ทำงาน มีชั้นลดความเด่นของภาพและการ์ดสีขาว หากไม่เลือกภาพหรือโหลดภาพไม่ได้จะใช้พื้นเรียบ กดนำภาพออกและบันทึกเพื่อกลับพื้นเรียบ
