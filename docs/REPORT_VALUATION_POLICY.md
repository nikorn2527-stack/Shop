# ฐานราคาของรายงานสินค้า

ปรับตามคำยืนยันวันที่ 20 ตุลาคม 2569

## รายงานทั่วไป

- มูลค่าคงคลัง รายงานรับเข้า และรายการสั่งซื้อ ใช้ **จำนวน × ราคาขายต่อหน่วย** แม้สินค้านั้นจะมีต้นทุนจริงแล้ว
- ชื่อคอลัมน์หน่วยราคาและยอดรวมระบุฐานราคาขายให้ชัด
- หน้าจอ พรีวิว CSV Excel PDF และข้อมูลสำหรับพิมพ์ ใช้ฐานราคาเดียวกัน
- ยอดรวมคงคลังรวมเฉพาะสินค้าที่อยู่ในตัวกรอง ไม่รวมสินค้านอกแถวที่ส่งออก
- รับเข้าที่ไม่มีจำนวนรับเดิมยังแสดงว่าไม่ระบุจำนวน ไม่ใช้ยอดล็อตที่เหลือแทนยอดรับเดิม
- รายงานคงคลังใช้จำนวนขายที่ไม่ถูกยกเลิก ส่วนมูลค่าคงเหลือใช้จำนวนคงเหลือปัจจุบันและราคาขายปัจจุบัน

## ต้นทุนและกำไร

ผู้ใช้ยืนยันให้คงคอลัมน์กำไรและอัตรากำไรในรายงานเดิมไว้ก่อน ไม่ลบออก

- การคำนวณกำไรยังใช้ต้นทุนจริงที่บันทึกในการขาย/การจัดสรรมูลค่าล็อต
- ถ้าไม่มีข้อมูลต้นทุนจริง ใช้ราคาขายที่บันทึกตอนขายเป็นต้นทุนประเมิน สินค้าที่ยังไม่มีต้นทุนจึงไม่ถูกนับเป็นกำไรเต็มจำนวน
- ใบรับเข้าที่บันทึกต้นทุนศูนย์อย่างชัดเจนเป็นต้นทุนจริงศูนย์ ตามหลักการจัดสรรมูลค่าที่มีอยู่เดิม
- ไม่แก้ราคาขาย ต้นทุน บิล ล็อต หรือยอดสมาชิกในฐานข้อมูลเพียงเพื่อแสดงรายงาน

## ตรวจสอบ

- TypeScript และ production build ผ่าน
- Full regression: 352 tests / 48 files ผ่าน
- `scripts/report-valuation-smoke.mjs`: ฐานข้อมูลใหม่ใน `/tmp` ตรวจหน้าจอ พรีวิว และดาวน์โหลด CSV/XLSX/PDF จริงของคงคลังตามตัวกรอง รายการสั่งซื้อ และประวัติรับเข้า
- กรณีทดสอบ: ราคาขาย 20 ต้นทุนจริง 4 คงเหลือ 8 → มูลค่าคงคลัง 160; รับ 10 → มูลค่ารายงานรับเข้า 200; สั่ง 3 → มูลค่า 60
- ต้นทุนและกำไรยังใช้ต้นทุนจริง และกรณีไม่ทราบต้นทุนใช้ราคาขายแทน พร้อมตรวจว่าสต็อก บิล ล็อต และธุรกรรมสมาชิกไม่เปลี่ยนระหว่างอ่าน/ส่งออก
- ตรวจโครงสร้างและตัวเลขในไฟล์ PDF ผ่าน `pdftotext`; ไม่ได้พิมพ์ลงเครื่องพิมพ์จริง
