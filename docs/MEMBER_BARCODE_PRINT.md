# พิมพ์บาร์โค้ดลงสลิปแทนบัตรพลาสติก

สมาชิกและบัญชี → จัดการบัตรสมาชิก → เพิ่มบัตรเปล่า → สร้างเลขอัตโนมัติ
จากนั้นเลือกบัตรหนึ่งใบหรือหลายใบแล้วกด **พิมพ์บาร์โค้ด**
รองรับกระดาษ 58 / 72 / 80 มม. และเครื่องพิมพ์ใบเสร็จที่ตั้งไว้บนเครื่องนั้น
พรีวิวแสดงเอกสารก่อนพิมพ์ มีเส้นคั่นระหว่างใบสำหรับตัดไปแปะ

สแกนรหัสบนสลิปในขั้นตอนจ่ายบัตรให้สมาชิกตามปกติ บัตรเปล่าจะยังทำธุรกรรมไม่ได้จนกว่าจะจ่ายและเปิดใช้
การพิมพ์หรือพิมพ์ซ้ำไม่เปิดใช้บัตร ไม่เพิ่มบัตร ไม่เปลี่ยนยอดเงินหรือประวัติ
บัตรที่แจ้งหายหรือชำรุดไม่มีปุ่มพิมพ์ในสต็อกบัตร

หน้ารายละเอียดสมาชิกและการเลือกหลายคนในรายชื่อสมาชิกมีปุ่มพิมพ์บาร์โค้ดเช่นกัน
หากสมาชิกมีเลขบัตรจะเข้ารหัสเลขบัตรนั้น หากยังไม่มีจะเข้ารหัสเลขสมาชิกสำหรับระบุตัวตน
ระบบสแกนรับทั้งสองรหัส แต่ยังตรวจสถานะบัตรและสมาชิกก่อนทำธุรกรรมเหมือนเดิม
สลิปไม่พิมพ์ยอดคงเหลือ ข้อมูลบัตรสมาชิกแบบเต็มและ PDF เดิมยังใช้ได้

Code128-B ใช้ตัวอักษร ASCII ที่พิมพ์ได้ ปฏิเสธรหัสที่ไม่รองรับแทนการแทนอักษรผิด
คงช่องว่างข้างบาร์อย่างน้อย 10 โมดูลและขนาดโมดูลอย่างน้อย 2 จุดที่ 203 dpi
หากรหัสยาวเกินพื้นที่พิมพ์จะให้เลือกกระดาษกว้างขึ้น แทนการบีบจนอ่านไม่ได้
ใช้การวัดเอกสารจริงและโปรไฟล์เครื่องพิมพ์เดิม เบราว์เซอร์ใช้ขนาดกระดาษจากไดรเวอร์
ควรพิมพ์ที่สเกล 100% และทดลองอ่านจากสลิปจริงก่อนแจกใช้งาน

ตรวจสอบ:

- `scripts/member-barcode-print-smoke.mjs`: ฐานข้อมูลชั่วคราวใน /tmp, พรีวิวรายคน/หลายคน, สต็อกบัตร, ถอดรหัสภาพ, ขนาดกระดาษ 3 ขนาด, PDF บนไดรเวอร์ยาว 200 มม., มือถือ, สแกนเข้า POS และยืนยันว่าการพิมพ์ไม่เปลี่ยนข้อมูล
