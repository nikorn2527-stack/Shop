# นำเข้าสต็อกใหม่โดยเก็บบิลเดิม

ใช้ที่ **ตั้งค่า → ระบบและความปลอดภัย → นำเข้าข้อมูล → สินค้าและสต็อก**

1. เลือกไฟล์ Excel หรือ CSV และจับคู่คอลัมน์ ต้องมีชื่อสินค้า บาร์โค้ดหรือรหัสสินค้า และจำนวนสต็อก
2. เลือก **ยอดตั้งต้นก่อนขายวันนี้** เมื่อจำนวนในไฟล์ยังไม่ได้หักยอดขายวันนี้
3. กด **ตรวจสอบยอดก่อนนำเข้า** ตรวจตาราง `ตั้งต้น − ขายวันนี้ = คงเหลือ` ก่อนยืนยัน
4. ระบบสำรองฐานข้อมูลก่อนบันทึก แล้วปรับสินค้าและยอดล็อตพร้อมกัน

ตัวอย่าง: ไฟล์ระบุ 100 ชิ้น ขายวันนี้แล้ว 2 ชิ้น จะบันทึกคงเหลือ 98 ชิ้น การนำเข้าไฟล์เดิมซ้ำจะคำนวณจาก 100 ใหม่ จึงไม่หักยอดขายซ้ำ

## ข้อมูลที่คงไว้

- จับคู่ด้วยบาร์โค้ดหรือ SKU เก็บรหัสภายในของสินค้าเดิมไว้ ไม่จับคู่จากชื่ออย่างเดียว
- เก็บบิล รายการชำระเงิน ยอดสมาชิก ประวัติยอดเงิน และราคากับต้นทุนที่บันทึกในบิลเดิม
- เก็บล็อตเก่าและการอ้างอิงจากบิลไว้ ปิดยอดล็อตเก่าแล้วสร้างยอดยกมาใหม่ จึงยังยกเลิกบิลเดิมได้
- เปลี่ยนเฉพาะสินค้าที่อยู่ในไฟล์ สินค้าที่ไม่ได้อยู่ในไฟล์ยังคงเดิม
- ราคาขายตามคอลัมน์ราคาขาย หากไม่ระบุต้นทุนในไฟล์ ใช้ 0 เป็นข้อมูลต้นทุนที่ยังไม่ทราบ ไม่อนุมานจากราคาขาย

## การตรวจสอบก่อนบันทึก

- ใช้วันที่ปัจจุบันตามเวลาไทย หักเฉพาะยอดขายวันนี้ที่ยังไม่ถูกยกเลิก
- ยอดตั้งต้นว่าง ติดลบ ไม่เป็นจำนวนเต็ม น้อยกว่ายอดขาย หรือรหัสซ้ำ/กำกวม ต้องแก้ก่อนนำเข้า ทั้งไฟล์ยังไม่ถูกบันทึก
- ถ้ามีการขาย รับเข้า หรือแก้ข้อมูลสินค้าระหว่างพรีวิวกับยืนยัน ระบบจะให้ตรวจยอดใหม่
- บันทึกทั้งไฟล์ในธุรกรรมเดียว หากบันทึกล้มเหลวจะย้อนกลับทั้งไฟล์
- CSV รักษาศูนย์หน้ารหัส เช่น `01`; Excel รักษารหัสที่จัดรูปแบบเป็น `00001` ตามที่แสดงในเซลล์

กรณีไฟล์เป็นยอดที่หักยอดขายแล้ว ให้เลือก **ยอดคงเหลือปัจจุบัน** แล้วเลือกวิธีจัดการรายการซ้ำตามต้องการ โหมดนี้ใช้จำนวนในไฟล์โดยตรง
